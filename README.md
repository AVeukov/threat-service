# Сервис информации об угрозах

Тестовое задание на Go. Сервис позволяет добавлять угрозы, получать их по MD5
и обновлять. Используется только стандартная библиотека Go.

Данные хранятся в памяти и удаляются после остановки сервера.

## Запуск

Нужен Go 1.25 или новее. В папке проекта:

```sh
go run .
```

Сервер будет доступен по адресу `http://localhost:8080`.
Другой адрес можно задать через переменную окружения `ADDR`.

Или через Docker:

```sh
docker build -t threat-service .
docker run --rm -p 127.0.0.1:8080:8080 threat-service
```

## Запросы

- `POST /info` — добавить угрозу;
- `GET /info/{md5}` — получить угрозу;
- `PUT /info/{md5}` — обновить угрозу.

Для POST и PUT нужен заголовок `Content-Type: application/json`.
Пример тела POST:

```json
{
  "md5": "d41d8cd98f00b204e9800998ecf8427e",
  "name": "Trojan.Win32.Generic",
  "description": "Steals browser passwords",
  "severity": "high"
}
```

При создании обязательны `md5` и `name`. MD5 должен состоять из 32
шестнадцатеричных символов. Название — от 1 до 200 символов, описание — до 2000.
Уровень опасности: `unknown`, `low`, `medium`, `high` или `critical`.
Сервер сам добавляет даты создания и обновления.

Для PUT передаются те же поля, кроме `md5`. Обязательно только `name`.
Если не передать описание и уровень опасности, они сбросятся в пустую строку
и `unknown`. Несуществующую запись обновить нельзя.

Ошибки: 400 — неверный запрос, 404 — запись не найдена, 409 — такой MD5 уже есть.
Полная спецификация находится в [openapi.yaml](openapi.yaml).

## Тесты

```sh
go test ./...
go vet ./...
```

Тесты проверяют валидацию, работу API и одновременные запросы.
Для проверки гонок: `go test -race ./...` (на Windows нужен 64-битный GCC).
